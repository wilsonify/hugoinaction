Hugo Flavors
====

Hugo comes in two flavors:

Standard – minimal, no SCSS support.

Extended (recommended) – includes SCSS compilation support.

Always install the extended version, as it unlocks more features.


# Checking Hugo Version

```hugo version```

This shows both the version and whether you’re using the extended flavor.
We recommend using the latest stable version unless otherwise noted.

The book’s examples use Hugo v0.91.2.

Hugo does not guarantee backward compatibility, but migration steps are usually simple.
