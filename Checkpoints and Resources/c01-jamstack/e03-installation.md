Installation

You can install Hugo using a package manager or via direct download.

Direct Download
Grab binaries from GitHub releases
```commandline
mv hugo /usr/bin/
```
 
macOS:

```commandline
brew install hugo
sudo port install hugo +extended
```

Linux
```commandline
# Snap (recommended)
snap install hugo --channel=extended

# Ubuntu/Debian
sudo apt-get install hugo

# Arch Linux
sudo pacman -Syu hugo

# Fedora
sudo dnf install hugo
```
